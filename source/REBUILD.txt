Source snapshot for the included firmware. Third-party components retain
separate licenses. The exact covered Eigen headers are included here.

External prerequisites (not binaries from the private prototype):
- Arm GNU Toolchain 14.3.rel1, arm-none-eabi target, native build tools, Python 3.
- git clone --recursive https://github.com/sdatkinson/NeuralAmpModelerCore into
  host-research/NeuralAmpModelerCore-current and checkout
  0b3d3c97b0859a3a8c92a8628c4dd89a25eb5842;
  update its submodules at that revision.
- git clone --recursive https://github.com/electro-smith/libDaisy into
  vendor/libDaisy and checkout f715e4875b2d28445d0c11a0a17f064a248f69d0;
  update its submodules at that revision.
- From this source folder: make GCC_PATH=/absolute/path/to/toolchain/bin

The locally authored source files and approved model header are included. NAM,
libDaisy and JSON source can be obtained from the pinned upstream repositories;
their original license texts are in ../licenses. Generated NAM adaptation files
are regenerated by the included tool. The packaged application source was rebuilt in an isolated folder and produced
the exact installed binary. This check used the same toolchain and pinned,
unmodified local dependency trees (including the existing libDaisy archive); a
separate clean-machine test has not been done. No private models are needed or included.
