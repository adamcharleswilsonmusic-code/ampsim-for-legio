CHORUS / SWELL / LOCAL APPLICATION
The chorus is the project's local stereo_chorus.h implementation, using an
allocated mono delay history, interpolated opposed taps, a polynomial-smoothed
triangle LFO and a dry/wet blend. No external chorus library or copied named
commercial chorus implementation was found in the reviewed build inputs. The
swell, controls, gain-CV code, meters and firmware glue are local project source.
The review identifies source provenance and licenses; it does not establish an
exclusive ownership claim over standard DSP mathematics or certify every
possible patent/trademark issue. Third-party names are descriptive credits,
not endorsements.

OTHER ASSETS / PACKAGING
Manufacturer printable artwork in Downloads and source-panel.svg has no
redistribution grant established by this audit; exclude those original files
from a firmware release. The local panel guide is a custom reference drawing.
Embedded Liberation fonts have a separate included font license. No manufacturer
logos, commercial IR files or downloaded demo audio are needed by the firmware.
The public package contains only the approved firmware, model, application
source, guides, notices/licenses and required covered source. Private development
files, legacy images, manufacturer printables and device backups are excluded.

VALIDATION AND LIMITS
The approved RiffSmith Lite model has the exact supported 1,871-weight topology.
Host output matches the model source; no callback allocation, dry fallback,
stereo chorus and original swell checks pass. The lower drive floor reaches
inference, with old drive values and gain-CV voltage scaling preserved. The
new public build does not incorporate the prior private capture weights in the
checked binary scan. Firmware hardware/listening state is recorded separately.
This is an evidence-based source/asset license review of the listed build, not
a guarantee about unrelated files, future changes or every legal question.
